# RAD Agent — Phase 1 Audit (2026-09-17)

Scope: every module in `rad/`, all tests, `pyproject.toml`, README. Findings were
confirmed by executing the code paths, not by reading alone.

## Architecture map (as found)

| Layer | Module | State |
|---|---|---|
| Storage | `home.py` | JSON/markdown under `~/.rad`; atomic writes; no migrations |
| Providers | `providers.py` | OpenAI/Anthropic/Gemini wire formats, streaming + non-streaming, tool-call translation |
| Routing | `router.py` | local → free (round-robin) → paid; per-call chain rebuild; cost tracking |
| Agent loop | `session.py` | streaming tool loop, memory + world context injection, text-protocol tool fallback |
| Tools | `tools.py` | shell/files/web/vision/spawn_agents/MCP; confirm gate + regex blocklist |
| Memory | `memory.py` | markdown files, Jaccard recall, strength decay, sleep consolidation |
| Identity | `dna.py` | generational persona/style JSON, rollback |
| Planning | `plan.py`, `planrun.py` | linear step list; runner drives `Session` per step |
| Teams | `team.py` | sequential role-prompted calls + synthesis |
| World | `world.py` | entity/relation JSON, regex fallback, optional kuzu mirror |
| Eval | `battery.py`, `brains.py` | deterministic graders; candidate promotion by score margin |
| Ops | `jobs.py`, `sleep.py`, `drive.py`, `voice.py`, `mcp.py`, `cli.py` | |

## Defects found and fixed in this phase

1. **Every non-streaming LLM call crashed** (`providers.py`). `_http()` returns
   `bytes` when not streaming; all three parsers called `.read()` on it. Chat
   streams so it worked; battery, brain promotion, teams, sleep, plan creation,
   world extraction and vision all went through this path and were dead. Tests
   passed because they mocked `P.chat` above the bug. *Fixed; parsers now
   tested against a fake `_http`.*
2. **`see_image` passed `max_tokens` to `RouterState.chat`, which did not accept
   it.** Vision always returned "no vision provider". *Fixed.*
3. **`build_caller` un-pinned the provider after the first call** (`battery.py`).
   Brain battles benchmarked question 1 on the candidate and the rest on the
   default chain. The promotion gate was not measuring what it claimed. *Fixed;
   pin now applied per call.*
4. **`planrun` inferred success from silence.** A reply with neither `DONE:`
   nor `BLOCKED:` was marked done. *Now marked `unverified`/blocked and halts;
   legacy behaviour opt-in via `plan_infer_done: true`.*
5. **File tools had no workspace boundary.** Unconfirmed `read_file` could read
   `~/.ssh/*` via absolute paths or `..`. *Workspace is now enforced for
   read/write/list; opt-out via `allow_outside_workspace: true`.*

## Known gaps carried into later phases

- No explicit task state: goals/retries/verification live only in the chat
  transcript (→ Phase 2 control plane).
- Shell blocklist is regex; `rm -rf ./*`, `python -c "shutil.rmtree(...)"` pass
  (→ Phase 6 capability-based permissions + sandbox).
- Memory recall is bag-of-words over a full rescan per turn (→ Phase 4).
- World model without a brain is a capitalised-word regex (→ Phase 4).
- Teams are sequential and share no state (→ Phase 5).
- Untrusted-web wrapper is a prompt marker only (→ Phase 6).
- No migrations; storage is flat JSON (→ Phase 9).
